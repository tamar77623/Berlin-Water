# 💧 Berlin Water - Landing Page & Ordering System

A modern, fast, and responsive web application built for **Berlin Water**, a premium drinking water trading company. The project showcases high-quality branding, interactive order calculations, and a sleek user interface tailored for seamless customer engagement.

---

## ✨ Key Features

* ** Modern Hero Section:** Engaging headline featuring the brand slogan *"انطلق بنقاء!"* (Launch with Purity).
* ** Interactive Order Calculator:** Allows users to select bottle packs, quantities, apply discounts, and instantly calculate the total price before placing an order.
* ** Sleek Dark & Aqua UI:** Styled with Tailwind CSS using smooth gradients, glassmorphism containers, and high contrast for ultimate readability.
* ** Fully Responsive Design:** Optimized for mobile phones, tablets, and desktop displays.
* ** Fast Performance:** Built with pure Vanilla JavaScript to ensure lightweight and instant interactions.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, Tailwind CSS
* **Scripting & Logic:** Vanilla JavaScript (ES6+)
* **Deployment:** Vercel

---

## 🚀 Getting Started Locally

To run this project on your local machine:

1. Clone the repository using Git CLI on your machine.
2. Navigate into the project directory.
3. Open `index.html` directly in your browser or launch via VS Code **Live Server**.
